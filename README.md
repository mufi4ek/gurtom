# Ґуртом / Together — пакет для старту розробки

Android-застосунок із 10 іграми для компанії. Українська + англійська,
темна база з настроюваним неоновим акцентом, безкоштовно з рекламою,
офлайн + локальне лобі по Wi-Fi/хотспоту. Бренд — **mufidev**.

```bash
cd tools && python3 download.py && python3 cats.py && python3 extract.py \
  && python3 signals.py && python3 family_freq.py && python3 build_dataset.py
```

## Перші 3 кроки, щоб отримати APK

1. Створи репозиторій `mufidev/gurtom`. Поклади туди `PLAN.md`,
   `app-notes/DATA_SCHEMA.md`, `ci/android-build.yml` →
   `.github/workflows/android-build.yml`, і `dataset/gurtom.db.gz` →
   `app/src/main/assets/gurtom.db.gz`.
2. Надішли кодеру **ПРОМПТ 0** з `PROMPTS.md` — він створить проєкт.
3. Після пуша зайди в GitHub → Actions → останній run → Artifacts →
   `gurtom-debug-<sha>` → там APK.

Далі — промпти 1…24 по черзі. Мінімальний шлях до «пограти сьогодні»:
промпти **0–5** (скелет, дизайн, дані, рушій, Аліас).
